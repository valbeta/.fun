# Val_beta v0.3

## 版本定位

v0.3 是 valbeta.fun 的第一个可供完整上线测试的静态内容版本。它保留 mockup v1.1 的 Future Laboratory × Open Source Culture 视觉方向，并建立了可通过 Git 管理的内容发布基础。

当前版本不包含数据库、CMS、用户系统或运行时 API。网站由 Next.js 构建为静态文件，再由 ECS 上的 Nginx 提供服务。

## 已实现特性

### 网站结构

- Homepage
- Ideas
- Explore
- Observe
- About
- 文章详情页
- 自定义 404 页面
- 全局错误页面
- Loading 页面

### 内容系统

- 内容存放在 `content/ideas`、`content/explore` 和 `content/observe`
- 支持 Markdown 和 MDX 文件
- 使用 YAML frontmatter 管理标题、摘要、日期、状态和 tags
- 仅发布 `status: published` 的内容
- 使用 `gray-matter` 解析 frontmatter
- 使用 `next-mdx-remote` 生成静态 MDX 内容
- 使用 Shiki 和 `rehype-pretty-code` 进行代码语法高亮
- 内容构建前自动校验

### Homepage Hero map

- `VAL_BETA / NOW` 中心节点
- 五节点环形几何布局
- 中文名、英文名和最新匹配文章标题
- 根据专属 tag 自动寻找最新文章
- 根据 `updated` 或 `date` 判断状态灯：
  - 7 天内：绿色
  - 30 天内：橙色
  - 超过 30 天或没有匹配内容：灰色
- 节点框宽度根据文字长度自动适应
- 连接线动态连接到节点边缘中心

### 视觉和交互

- mockup v1.1 暗色实验室视觉系统
- GitHub Dark 色彩方向
- Inter、JetBrains Mono 和自托管 Noto Sans SC
- 桌面端和移动端响应式布局
- reduced-motion 支持
- 键盘焦点样式
- Skip to content 辅助导航
- 页面级 hover 和状态反馈

### SEO 和工程基础

- 中文 metadata
- canonical URL
- Open Graph 和 Twitter metadata
- sitemap.xml
- robots.txt
- 静态导出模式
- 静态路由 smoke test
- TypeScript strict mode
- ESLint
- frontmatter schema 校验
- GitHub Actions 构建和 ECS release 部署
- `current` 符号链接原子切换

- Nginx 安全响应头示例

## 当前验证结果

- `npm run check` 通过
- 13 个静态路由生成成功
- 11 个关键静态导出文件验证通过
- MDX TypeScript 代码块已验证
- Hero map 桌面端和移动端几何布局已验证
- 尚未推送或合并到 `main`

## v0.3 的已知边界

- 当前内容数量较少，部分 Hero map 节点仍显示 `NO PUBLIC NOTE YET`
- 中文内容尚未全面覆盖所有文章
- 当前没有真实 ECS 部署后的 smoke test 结果
- 尚未完成正式域名下的 Lighthouse、搜索引擎和性能评估
- 尚未接入网站分析、站点监控或自动化 uptime 检查
