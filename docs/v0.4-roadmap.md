# Val_beta v0.4 迭代规划

v0.4 只在 v0.3 完成多轮测试并修复阻塞问题后开始。它的目标不是重做视觉基础，而是让内容发布、观察和维护更成熟。

## 版本目标

- 提升内容创作和发布效率
- 增强中文和英文内容体验
- 提升站点可发现性和运营可观测性
- 保持静态导出和低运维成本
- 不引入数据库、CMS 或不必要的运行时服务

- [ ] 将现有 `.md` 内容迁移为 `.mdx`

- [ ] 增加内部链接有效性校验
- [ ] 为 Hero map 专属 tags 建立内容命名规范

## 暂不计划

以下功能不属于 v0.4 默认范围：

- 数据库
- CMS
- 用户注册和登录
- 评论系统
- 站内实时搜索服务
- 服务端 API
- 后台管理面板

如果未来内容规模或互动需求明显增长，再单独评估这些能力是否值得引入。

## v0.4 完成标准

- 内容组件和 MDX 规范稳定
- 中文/英文内容策略明确
- 正式 SEO 分享资产就位
- 部署后 smoke test 可重复执行
- Lighthouse 和浏览器回归基线建立
- `npm run check`、部署测试和回滚测试全部通过
